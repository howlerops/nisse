# Is Nisse worth doing? Evaluation, Oct 24, 2026

Five independent evaluations, run in parallel, each looked at one question: the market, the agent-first bet, whether v1 is feasible, whether the parity line is worth its cost, and a red-team of every planning document. This page records their verdicts and evidence, and what changed in the [PRD](../PRD.md) and [ledger](../ledger/README.md) as a result. The claims about Go 1.27 and the TypeScript 7.1 API were re-checked against primary sources before any edit.

## Verdicts

| Question | Verdict | Confidence |
| --- | --- | --- |
| Is there a market? | v1: worth it with changes. Parity line as scoped: not worth it | ~60% / ~75% |
| Is the agent-first bet sound? | Half right: the checker-and-fixes loop is supported, TypeScript fluency as the source of the gain is not | ~65% that Nisse beats plain Go on its own suite; ~30% that the old targets were reachable |
| Is v1 feasible in 22 weeks? | Buildable, but not in 22 weeks: about 45–55 weeks as scoped, or 22–26 weeks for a cut-down preview | Medium (±25%) |
| Is the parity line worth its cost? | Cut it down hard; don't keep it as written | ~80% |
| Are the documents consistent? | 39 issues found, 6 high severity; all fixed or turned into decisions | — |

**Overall:** v1 is worth building, but only after a cheap experiment proves the bet, with a smaller first release and Go interop as the pitch. The parity line, as written, is a multi-year research programme, and the evaluations converge on committing only to backend ports (phases 4–7) after 0.1 shows real adoption.

## What the evidence says

### Market

- **Tov is interest, not demand.** 753 stars two weeks after launch, one committer, two Hacker News posts at 4 and 3 points, benchmarks publicly disputed on Oct 22. It is also ahead of Nisse on running existing TypeScript (it compiles `.ts`, keeps UTF-16 strings, runs Node/Bun APIs and npm on JavaScriptCore).
- **The "one binary from TypeScript" slot is taken.** Anthropic acquired Bun in Dec 2025 and ships Claude Code as a Bun-compiled binary; Cloudflare absorbed the Deno team on Oct 9, 2026. Independent TypeScript runtimes have not stood alone, so Nisse should not be positioned as one.
- **Encore.ts now also pitches agents** (an MCP server, `llms.txt`). Its 9× figure is its own; Elysia's re-run put Elysia at about 2× Encore, and no independent real-app number exists. The PRD's earlier "1.2–1.5× in real apps" came from a weak secondary source and was removed.
- **No mature TypeScript-to-Go transpiler exists** (only toys and `i2y/ramune`'s experimental one), which signals the problem is hard more than that it is open.
- **The wedge is Go interop:** typed Go imports, readable Go output, no JS engine in the binary. The buyer is a team running Go services whose agents write TypeScript more reliably than Go. Supporting signal: TypeScript became GitHub's most-used language in 2025, attributed to AI; Armin Ronacher's "A Language for Agents" (Feb 2026) lists properties v1 already has.

### The agent-first bet

- **The premise was wrong.** On repository-level agent benchmarks TypeScript is among the weakest languages and Go is roughly level with it: SWE-bench Multilingual JS/TS 34.9% vs Go 31.0%; Go ≥ TypeScript in most Multi-SWE-bench rows; SWE-PolyBench TypeScript 4.7–13.0%.
- **The loop is supported, with modest gains.** Type-checker feedback adds about 4–9 points; nearly all of it comes from the first iteration, so a median fix loop of 2 is plausible. A short syntax reference took GPT-5 from 4% to 54% on an unseen language (Cangjie); adding a compiler loop reached 78%.
- **Familiar syntax cuts both ways.** Models drift back to habits from similar-looking languages, so each Nisse divergence (`const` arrays, `.length`, `int`/`f64`, truthiness) will fire often on the first check. A reference in a familiar language even lowered scores (Cangjie code-to-code: 54% → 38%).
- **Wrong fixes are worse than none.** A type constrainer that rejects valid programs cut correctness by up to 97% in one study.
- **Cheapest test:** a two-week "paper compiler" experiment needing no real compiler (now W1-14).

### v1 feasibility

- **Comparables:** Gleam took five years to 1.0; Borgo (Rust-like to Go, solo) was "in no way complete" after a year; Microsoft's TypeScript port to Go took about two years with a full test suite to port against.
- **Technical errors found and verified:**
  - Go 1.27 (Aug 2026) allows generic methods on concrete types, not interfaces.
  - Go 1.27 resolves relative `//line` paths against the generated file's directory.
  - `-overlay` needs files on disk.
  - `errgroup` is not in the standard library.
  - Go type parameters cannot read struct fields.
  - Class methods were not covered by the export rules, so they couldn't satisfy Go interfaces.
- **Metrics:** with 50 tasks run once, the confidence interval is about ±11 points, too wide to detect a +10 difference. "Warm" check latency was undefined for a CLI.

### Parity line

- **Node compatibility is a funded-team, multi-year job.** Deno 2.8 passes 76.4% of Node's own tests; Bun 1.4 passes about 97% for core modules after roughly five years with around ten engineers.
- **Agents alone fail whole-repo language rewrites** (5.6/100 on SWE Refactor Bench). Agents inside a deterministic harness (compiler, tests, diff judge) have done large ports (Anthropic's Bun Zig→Rust, Airbnb's 3,500-file test migration). So `nisse port` is most valuable as the harness that makes an agent port converge, not as a complete rules table.
- **A redundancy:** wave 11 built a second TypeScript-compatible checker while D-16 already vendors TypeScript 7's own.
- **Money pits:**
  - Go-rendered React SSR and a Next.js-style framework
  - NestJS at full test parity
  - a Prisma client on Go drivers (the official Go client stayed alpha and was archived in Jul 2025)
  - the top-500 npm dashboard
  - `Intl` and `worker_threads`
- **Best value:**
  - the port tool built on TypeScript 7
  - the verification harness
  - the event-loop executor
  - a narrow set of Node core modules
  - compat packages that wrap Go libraries
  - tier 1 and 1b as gates
